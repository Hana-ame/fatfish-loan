# 肥鱼贷 · Fat Fish Loan

一个纯前端的恶搞演示页：假装用「哈气 + 爪击」双因子生物识别完成 20 万贷款放款。

> ⚠️ **纯属娱乐**：不会真的放贷，也不会采集、录制、上传任何真实生物信息。

## 三步流程

| 步骤 | 动作 | 实现 |
| --- | --- | --- |
| 1 | 哈气 | `getUserMedia({audio})` + WebAudio `AnalyserNode` 计算 RMS 音量，持续超过阈值推进进度条；**麦克风不可用可随时点「跳过哈气」** |
| 2 | 爪击 | 前置摄像头逐帧灰度差（64×48 降采样）做运动检测，3 次有效挥动通关；摄像头不可用时降级为触屏快速划动 |
| 3 | 放款 | 撒花 + 音效 + 随机合同号；语音播报走 mp3，失败则系统 TTS 兜底 |

所有识别都在浏览器本地完成，页面没有任何网络上报请求。

## 跳过哈气

第一步底部固定有一条次级按钮「麦克风用不了？跳过哈气」，点一下直接进入爪击验证。
适合手机浏览器不弹授权框、录音被系统 App 占用、或页面跑在受限 WebView 里的情况。

拿不到麦克风时页面**不会自动假装通过**，而是说明原因（权限被拒 / 没检测到设备 / 被占用）
并引导用户点跳过；授权请求超过 8 秒没有结果也会给出同样提示。
「跳过哈气」随时可用，重复点「重试麦克风」也只会重新请求一次音频权限。

## 语音

`index.html` 里的 `VOICE` 目前是占位地址（`https://your-cdn.example.com/voice*.mp3`），
加载失败会自动回落到系统 TTS，所以开箱即用。想换成真人语音，把这三行改成自己的 mp3 直链即可
（跨域 mp3 不需要 CORS 头，也**不要**设置 `crossOrigin`）。

## 本地预览

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
# 注意：麦克风 / 摄像头需要 https 或 localhost 才可用
```
