# 肥鱼贷 · Fat Fish Loan

一个纯前端的恶搞演示页：假装用「哈气 + 爪击」双因子生物识别完成 20 万贷款放款。

> ⚠️ **纯属娱乐**：不会真的放贷，也不会采集、录制、上传任何真实生物信息。

## 三步流程

| 步骤 | 动作 | 实现 |
| --- | --- | --- |
| 1 | 哈气 | `getUserMedia({audio})` + WebAudio `AnalyserNode` 计算 RMS 音量，轻声哈气即可推进 |
| 2 | 爪击 | 前置摄像头逐帧灰度差（64×48 降采样）做运动检测，阈值随噪声自适应，3 次有效挥动通关；识别不到可直接点圆框，摄像头不可用时降级为触屏点按/划动 |
| 3 | 放款 | 撒花 + 音效 + 随机合同号；语音播报走 mp3，失败则系统 TTS 兜底 |

所有识别都在浏览器本地完成，页面没有任何网络上报请求。

## 判定参数（已调宽松）

**哈气**（已放到几乎「只要有气流就过」）：
- 触发阈值 `rms≈0.0035`，比正常呼吸略响一点就开始累计；`rms≈0.006` 约 1.5 秒填满；
- 麦克风约束开启 `autoGainControl`，手机上的轻声音量会被自动放大；
- 底噪自适应：安静环境阈值按 `底噪*1.5+0.001` 缓慢抬高，空调/风扇不会误触发；
- 页面自己的语音播报期间不累计，避免外放提示音被麦克风拾到后「自己把自己吹过」；
- **进度只增不减**：中途停一下、切到后台、被系统打断都不会回退，回来接着累计；
- 旧版要求 `rms>0.060`（对着麦克风用力吹）——这是「声音要很响」的根因。

**爪击**：
- 触发阈值 `= max(8, 噪声基线+3)`，回落阈值 `= max(4.4, 噪声基线+2)`，带回差防抖；
- 两次爪击最小间隔 320ms，安静 220ms 后重新武装；
- 画面一直有噪声/动作时，距上次命中 1 秒强制复位——**旧版只有第一次能计数，就是这里卡死的**；
- 识别不到挥动时，直接点圆框也算一次爪击（320ms 冷却）；触屏兜底模式下轻点也算；
- **爪击不回退**：命中次数只增不减，运动条记录峰值、只涨不落；切后台/重进摄像头也保留已有进度。

现场排查：`__clawDebug()` 返回爪击的 `base / env / hi / lo / armed / hits`；
`__blowDebug()` 返回哈气的 `rms / floor / threshold / level / progress / voiceBusy`。

## 麦克风不可用时

页面**不会自动假装通过**：拿不到麦克风时会在提示区说明原因（权限被拒 / 没检测到设备 / 被占用），
主按钮变成「重试麦克风」，点一下重新请求一次音频权限；授权请求超过 8 秒没有结果也会给出同样提示。
第一步没有跳过入口，麦克风必须可用才能继续。

## 语音

三句提示音是仓库自带的中文语音，用相对路径加载，不依赖外部 CDN，也不会有跨域 / 防盗链问题：

| 文件 | 内容 | 时长 |
| --- | --- | --- |
| `voice/voice1.mp3` | 请完成哈气动作 | 2.16s |
| `voice/voice2.mp3` | 请完成爪击动作 | 2.14s |
| `voice/voice3.mp3` | 恭喜您完成贷款二十万元 | 3.00s |

合计约 44KB。想换自己的声音：直接覆盖这三个文件，或改 `index.html` 里 `VOICE` 的路径。
mp3 播放失败仍会回落到系统 TTS（`TTS_FALLBACK`）。

第 1 步的顺序是「先播完提示音，再开麦克风」：一旦调用 `getUserMedia`，iOS/Android 会把音频会话
切到录音通路，外放提示音会被压低、甚至改走听筒，所以麦克风要等第 1 句（2.16s）播完才启动。
第 2、3 步的语音在播报前也会冻结哈气累计，避免外放被麦克风拾到后「自己把自己吹过」。

如果语音被浏览器拦截（提示条会写明），点页面任意处可借这次手势重试；
mp3 加载/播放失败会提示并回落到系统朗读。

移动端自动播放限制的处理：
1. 首次触摸 / 点击时把三句 mp3 解码成 `AudioBuffer`，之后用已解锁的 `AudioContext` 播放
   （`playVoiceBuffer`）——第 2、3 步由定时器触发也不会被自动播放策略静音；
2. 同时给 `<audio>` 元素做一次静音预热，解码失败时仍能退回元素播放；
3. 都不行才走系统 TTS。

重新生成（需要 `pip install edge-tts`，或换任意 TTS）：

```bash
edge-tts --voice zh-CN-XiaoxiaoNeural --text "请完成哈气动作"          --write-media voice/voice1.mp3
edge-tts --voice zh-CN-XiaoxiaoNeural --text "请完成爪击动作"          --write-media voice/voice2.mp3
edge-tts --voice zh-CN-XiaoxiaoNeural --text "恭喜您完成贷款二十万元"  --write-media voice/voice3.mp3
```

诊断：控制台 `__voiceDebug()` 返回三句的 `state / decoded / playingBuffer / readyState / paused / currentTime / duration`。
